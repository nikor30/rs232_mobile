Bestätigen

Das Gerät zeigt einen sechsstelligen Code – auf seinem Display (Seite Info) und in seiner Weboberfläche. Hier eintippen, was dort steht.

Fünf falsche Eingaben verwerfen die Anmeldung.

Aufträge

„Neustart“ und „Abspielen“ führt das Gerät nur aus, wenn das an ihm selbst erlaubt wurde (Menü → Netz → Leitstelle).

Gerät einladen

  1. Am Gerät den WLAN-Client verbinden – darüber erreicht es diesen Server.
  2. Mit dem Handy in den Hotspot des Geräts gehen und den Code scannen. Die Weboberfläche des Geräts öffnet sich mit dem Token; dort „Anmelden“ tippen.
  3. Das Gerät erscheint hier als „wartet“. Den Code von seinem Display eintippen.
