An diesem Schlüssel erkennen die Geräte den Server. Bei einem Wechsel erfährt jedes Gerät den neuen Schlüssel, sobald es sich meldet; bis dahin gilt für es der alte weiter.

Serverschlüssel wechseln

Der Server bekommt einen neuen Schlüssel. Jedes Gerät erfährt ihn bei seiner nächsten Meldung und wechselt von selbst.

  • Geräte, die sich in der Frist nicht melden, müssen danach neu angemeldet werden.
  • Offene Einladungen verfallen.
  • Wurde der alte Schlüssel gestohlen, reicht das nicht: dann den Wechsel sofort beenden und alle Geräte neu anmelden.

Gerät einladen

  1. Am Gerät den WLAN-Client verbinden – darüber erreicht es diesen Server.
  2. Mit dem Handy in den Hotspot des Geräts gehen und den Code scannen. Die Weboberfläche des Geräts öffnet sich mit dem Token; dort „Anmelden“ tippen.
  3. Das Gerät erscheint hier als „wartet“. Den Code von seinem Display eintippen.
