Devices recognise the server by this key. When it changes, every device learns the new key as soon as it reports in; until then the old one still counts for it.

Change the server key

The server gets a new key. Every device learns it the next time it reports in and switches by itself.

  • Devices that do not report in within the period have to be enrolled again afterwards.
  • Open invitations become void.
  • If the old key was stolen, this is not enough: end the change at once and enroll every device again.

Invite a device

  1. Connect the device's Wi-Fi client – that is how it reaches this server.
  2. Join the device's hotspot with a phone and scan the code. The device's web interface opens with the token; tap “Enroll” there.
  3. The device shows up here as “waiting”. Type in the code from its display.
