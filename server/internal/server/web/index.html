Change the server key

    
The server gets a new key. Every device learns it the next time it reports in and switches by itself.

    
    
      
  • Devices that do not report in within the period have to be enrolled again afterwards.
    • 
      
  • Open invitations become void.
    • 
      
  • If the old key was stolen, this is not enough: end the change at once and enroll every device again.
